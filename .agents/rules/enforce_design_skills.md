# Always Use Design Skills

For every prompt that involves creating, designing, refactoring, or updating any User Interface (UI), User Experience (UX), frontend code, or visual layouts, you MUST automatically apply the design constraints and aesthetics from the `impeccable` and `taste-skill` skills.

## Rules
- Treat `impeccable` and `taste-skill` as mandatory active context for all frontend tasks.
- If you are building a website, landing page, dashboard, or component, apply these high-end, premium, and anti-slop design directives automatically without needing explicit permission.
- Read and adhere to the guidelines found in `.agents/skills/impeccable/SKILL.md` and `.agents/skills/taste-skill/SKILL.md` when executing these tasks.
